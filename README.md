# Employee Management System Using SQL

## 📌 Project Overview

The Employee Management System is a database project developed using **MySQL** to manage and analyze employee-related information.

The project stores employee details and manages different areas such as departments, leaves, payroll, qualifications, salary, and bonuses.

## 🎯 Project Objectives

* Manage employee information efficiently.
* Store department and qualification details.
* Track employee leaves.
* Manage payroll information.
* Maintain salary and bonus details.
* Retrieve useful information using SQL queries.
* Analyze employee data using different SQL concepts.

## 🛠️ Technologies Used

* **Database:** MySQL
* **Tool:** MySQL Workbench
* **Language:** SQL
* **Data Format:** CSV

## 📂 Database Tables

The project contains the following main tables:

1. **Employee** – Stores employee details.
2. **Department** – Stores department information.
3. **Leaves** – Stores employee leave information.
4. **Payroll** – Stores payroll-related information.
5. **Qualification** – Stores employee qualification details.
6. **Salary_Bonus** – Stores salary and bonus information.

## 🔑 SQL Concepts Used

* DDL – CREATE, ALTER, DROP, TRUNCATE
* DML – INSERT, UPDATE, DELETE
* DQL – SELECT
* Constraints
* Primary Key
* Foreign Key
* Joins
* GROUP BY
* HAVING
* ORDER BY
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Views
* Aggregate Functions

## 📊 Key Operations

The project can be used to:

* Find employee details.
* Display employees department-wise.
* Analyze salary information.
* Calculate employee-related statistics.
* Find employees based on different conditions.
* Analyze payroll and bonus information.
* Retrieve leave-related information.
* Combine information from multiple tables using joins.

## 📁 Project Files

* `Database/` – Database creation and table scripts.
* `Data/` – CSV datasets used in the project.
* `Queries/` – SQL queries based on different concepts.
* `Documentation/` – Project report and data dictionary.
* `Screenshots/` – Database and query-result screenshots.
